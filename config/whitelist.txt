# ===========================================
# 白名单配置文件
#
# 白名单为空时：所有请求都允许通过（默认模式）
# 白名单非空时：仅允许匹配白名单规则的请求通过
# 支持以下格式：
#   - 精确域名: company.com
#   - 子域名通配: *.company.com
#   - 路径通配: company.com/api/*
#   - 正则表达式: /pattern/
#   - 注释行以 # 开头
# ===========================================

# --- 公司内部网站示例 ---
# company-intranet.local
# *.company.com
# company.com/api/public/*

# --- 教育网站示例 ---
# *.edu.cn
# scholar.google.com
